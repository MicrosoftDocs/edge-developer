# What's new in DevTools (Microsoft Edge 156)

These are the latest DevTools features in the Stable release of Microsoft Edge.


<!-- ====================================================================== -->
## Tool icons return to DevTools

<!-- Subtitle: We're bringing tool icons back to DevTools in Microsoft Edge 156. -->

We're bringing tool icons back to DevTools in Microsoft Edge 156.  Thank you for your feedback on how they support your workflows.  We're sorry for the disruption caused by the removal.


<!-- ====================================================================== -->
## Announcements from the Chromium project
<!-- https://developer.chrome.com/blog/new-in-devtools-november-2026 -->

Microsoft Edge 156 also includes the following updates from the Chromium project:

* [Elements: Visual position-area editor, implicit anchor selection, and CSS authoring updates](https://developer.chrome.com/blog/new-in-devtools-november-2026#elements_visual_position-area_editor_implicit_anchor_selection_and_css_authoring_updates)
   * Visual `position-area` editor
   * Implicit anchor selection on popover adorners
   * Anchor positioning box overlay
   * Inactive CSS styles for `@starting-style` and inherited rules
   * Multi-dash custom properties
   * Smarter class autocomplete
* [Application: Web Install manifest diagnostics, ad provenance, and storage table updates](https://developer.chrome.com/blog/new-in-devtools-november-2026#application_web_install_manifest_diagnostics_ad_provenance_and_storage_table_updates)
   * Web Install manifest diagnostics
   * Ad metric documentation tooltips and links
   * Cookies table: Restored row deletion using the keyboard or context menu
* [Network: Early Hints preload warnings and persistent overrides](https://developer.chrome.com/blog/new-in-devtools-november-2026#network_early_hints_preload_warnings_and_persistent_overrides)
   * Persistent local overrides
   * Persistent custom header columns
   * Copy raw request payloads
* [Memory: Dead context field detection in heap snapshots](https://developer.chrome.com/blog/new-in-devtools-november-2026#memory_dead_context_field_detection_in_heap_snapshots)
   * Dead context field detection in heap snapshots
* [Performance: Smoother timeline navigation and preserved call tree state](https://developer.chrome.com/blog/new-in-devtools-november-2026#performance_smoother_timeline_navigation_and_preserved_call_tree_state)
   * Preserved Call tree and Bottom-up state
* [Other highlights](https://developer.chrome.com/blog/new-in-devtools-november-2026#other)
   * Sensors: CPU Performance Tier control
   * Device Mode: Per-device scale and auto-adjust zoom preferences
   * Color Picker: APCA contrast color suggestions for light text on dark backgrounds
