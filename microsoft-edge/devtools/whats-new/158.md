# What's new in DevTools (Microsoft Edge 158)

These are the latest DevTools features in the Stable release of Microsoft Edge.  Microsoft Edge 158 includes the following updates from the Chromium project.
<!-- https://developer.chrome.com/blog/new-in-devtools-december-2026 -->


<!-- ====================================================================== -->
## Elements tool

* Force `:buffering` and `:stalled` media states.
* `position-try-fallbacks` swatch.
* Universal custom highlight selector (`::highlight(*)`).

See also:
* [Elements: Force :buffering and :stalled, position-try-fallbacks swatch, and CSS cascade fixes](https://developer.chrome.com/blog/new-in-devtools-december-2026#elements_force_buffering_and_stalled_position-try-fallbacks_swatch_and_css_cascade_fixes) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Application tool

* Sub apps inspection and Isolated Web App identity.
* Geolocation issues.

See also:
* [Application: Sub apps inspection, custom spellcheck dictionaries, and storage updates](https://developer.chrome.com/blog/new-in-devtools-december-2026#application_sub_apps_inspection_custom_spellcheck_dictionaries_and_storage_updates) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Performance tool and Memory tool

* Faster trace parsing and reduced memory usage.
* Lantern HTTP/2 simulation.
* Live heap timeline statistics scoped to the active recording view.

See also:
* [Performance and Memory: Faster trace parsing, Lantern HTTP/3 simulation, and generator context analysis](https://developer.chrome.com/blog/new-in-devtools-december-2026#performance_and_memory_faster_trace_parsing_lantern_http3_simulation_and_generator_context_analysis) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Network tool

* The WebSocket **Messages** tab reports correct UTF-8 byte lengths for non-ASCII text.

See also:
* [Other highlights](https://developer.chrome.com/blog/new-in-devtools-december-2026#other) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Device Mode

* Capturing a device screenshot copies it to the clipboard with a confirmation notification, in addition to downloading the file.

See also:
* [Other highlights](https://developer.chrome.com/blog/new-in-devtools-december-2026#other) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Accessibility

* **Accessibility live announcements**: Clicking a JavaScript-triggered announcement navigates to its call site in the **Sources** tool.  The pane can be resized, and its collapsed-pane behavior is corrected.
* **Keyboard focus indicators**: Improved focus-outline contrast in **Quick Open** results, data grid headers, and toolbar drop-down menus.
* **Screen reader semantics in Settings, Application, and Recorder**: The **Settings** dialog has an accessible name.

See also:
* [Accessibility improvements](https://developer.chrome.com/blog/new-in-devtools-december-2026#a11y) in _New in DevTools - December 2026_.
