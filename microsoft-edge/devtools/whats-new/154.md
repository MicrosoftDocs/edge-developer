# What's new in DevTools (Microsoft Edge 154)

These are the latest DevTools features in the Stable release of Microsoft Edge.  Microsoft Edge 154 also includes the following updates from the Chromium project:

* [Application: Ad script tracking in the Ads section, and cookie flag editing](https://developer.chrome.com/blog/new-in-devtools-october-2026#application_ad_script_tracking_in_the_ads_section_and_cookie_flag_editing)
* [Performance: Full soft navigation support, CPU performance tier overrides, and extension track search](https://developer.chrome.com/blog/new-in-devtools-october-2026#performance_full_soft_navigation_support_cpu_performance_tier_overrides_and_extension_track_search)
* [Elements: Inactive styles, keyboard-accessible adorners, and tree outline fixes](https://developer.chrome.com/blog/new-in-devtools-october-2026#elements_inactive_styles_keyboard-accessible_adorners_and_tree_outline_fixes)
* [Device Mode: Modernized device presets grouped by form factor](https://developer.chrome.com/blog/new-in-devtools-october-2026#device_mode_modernized_device_presets_grouped_by_form_factor)
* [Network: Edit and resend as fetch in Console, and local overrides security](https://developer.chrome.com/blog/new-in-devtools-october-2026#network_edit_and_resend_as_fetch_in_console_and_local_overrides_security)
   * Local overrides security hardening
* [Memory: Heap snapshot edge filtering, size sorting, and object querying](https://developer.chrome.com/blog/new-in-devtools-october-2026#memory_heap_snapshot_edge_filtering_size_sorting_and_object_querying)
* [Accessibility improvements](https://developer.chrome.com/blog/new-in-devtools-october-2026#a11y)
