# What's new in DevTools (Microsoft Edge 157)

These are the latest DevTools features in the Stable release of Microsoft Edge.  Microsoft Edge 157 includes the following updates from the Chromium project.
<!-- https://developer.chrome.com/blog/new-in-devtools-december-2026 -->


<!-- ====================================================================== -->
## Elements tool

* `position-area` alignment and IMCB overlay.

For more information, see [Elements: Force :buffering and :stalled, position-try-fallbacks swatch, and CSS cascade fixes](https://developer.chrome.com/blog/new-in-devtools-december-2026#elements_force_buffering_and_stalled_position-try-fallbacks_swatch_and_css_cascade_fixes) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Sources tool

* Original scope tree in the Scope view.
* Translated stack traces and logical stepping, across DevTools.
* Expression evaluation and autocomplete with original variable names.

For more information, see [Sources: Original scopes view, stack traces, and expression evaluation with ECMA-426 source map scopes](https://developer.chrome.com/blog/new-in-devtools-december-2026#sources_original_scopes_view_stack_traces_and_expression_evaluation_with_ecma-426_source_map_scopes) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Application tool

* Spellcheck custom dictionary inspection.
* File System site data clearing and reliable storage keys.

For more information, see [Application: Sub apps inspection, custom spellcheck dictionaries, and storage updates](https://developer.chrome.com/blog/new-in-devtools-december-2026#application_sub_apps_inspection_custom_spellcheck_dictionaries_and_storage_updates) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Performance tool and Memory tool

* Lantern HTTP/3 and ES module simulation.
* Heap snapshot context analysis for generators, async functions, and ES modules.

For more information, see [Performance and Memory: Faster trace parsing, Lantern HTTP/3 simulation, and generator context analysis](https://developer.chrome.com/blog/new-in-devtools-december-2026#performance_and_memory_faster_trace_parsing_lantern_http3_simulation_and_generator_context_analysis) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Network tool

* Search checks cached response bodies before querying the backend.  Request payload **Copy value** matches the displayed value, and **Show more** appears only for truncated text.

For more information, see [Other highlights](https://developer.chrome.com/blog/new-in-devtools-december-2026#other) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Console tool

* Copying selected message text excludes collapsed stack traces.  Long error-like strings no longer display as `[object Object]`.

For more information, see [Other highlights](https://developer.chrome.com/blog/new-in-devtools-december-2026#other) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Device Mode and Screenshots

* **Fit to window** selects the maximum fitting zoom percentage, and explicit zoom adjustments persist across reloads.

For more information, see [Other highlights](https://developer.chrome.com/blog/new-in-devtools-december-2026#other) in _New in DevTools - December 2026_.


<!-- ====================================================================== -->
## Accessibility

* **Accessibility live announcements:** Right-click an announcement row to reveal its associated node in the **Elements** tool or the **Accessibility** tree.
* **Screen reader semantics in Settings, Application, and Recorder**: Text prompts provide VoiceOver autocomplete semantics.  **Service Workers** update timing rows expose expandable button semantics, and **Recorder** step selection is more visible.

For more information, see [Accessibility improvements](https://developer.chrome.com/blog/new-in-devtools-december-2026#a11y) in _New in DevTools - December 2026_.
