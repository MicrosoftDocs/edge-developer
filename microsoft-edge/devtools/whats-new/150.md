# What's new in DevTools (Microsoft Edge 150)
<!-- https://learn.microsoft.com/microsoft-edge/devtools/whats-new/150 -->

These are the latest DevTools features in the Stable release of Microsoft Edge.  


<!-- ====================================================================== -->
## webhint deprecation

<!-- Subtitle: webhint will be removed from Edge DevTools in Edge 151.-->

Starting in Microsoft Edge 150, the webhint experiment is disabled by default.

In Edge 151, the webhint experiment will be removed.

To audit your site, use the [Lighthouse tool](https://developer.chrome.com/docs/devtools/lighthouse).
