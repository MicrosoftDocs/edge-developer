# Release SDK 1.0.3650.58, for Runtime 143 (Dec. 8, 2025)

Release notes for Microsoft Edge WebView2 SDK, release date: Dec. 8, 2025.

[NuGet package for WebView2 SDK 1.0.3650.58](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3650.58)

For full API compatibility, this Release version of the WebView2 SDK requires WebView2 [Runtime 143.0.3650.58 (Dec. 8, 2025)](../runtime/143.md) or later.
