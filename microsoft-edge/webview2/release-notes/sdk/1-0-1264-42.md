# Release SDK 1.0.1264.42, for Runtime 103 (Jul. 4, 2022)

Release notes for Microsoft Edge WebView2 SDK, release date: Jul. 4, 2022.

[NuGet package for WebView2 SDK 1.0.1264.42](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.1264.42)

For full API compatibility, this Release version of the WebView2 SDK requires WebView2 Runtime version 103.0.1264.42 or later.


<!-- ====================================================================== -->
## Promotions to Phase 3 (Stable in Release)

The following APIs have been promoted from Phase 2: Stable in Prerelease, to Phase 3: Stable in Release, and are now included in this Release SDK.


<!-- ------------------------------ -->
#### Context menu (right-click menu)

Added the `ContextMenuRequested` API, to enable the host app to create or modify its own context menu.

Previous phase: [Context menu (right-click menu)](./1-0-1189-prerelease.md#context-menu-right-click-menu) in _Prerelease SDK 1.0.1189-prerelease, for Runtime 100 (Mar. 10, 2022)_.  That's phase 1.  Phase 2 isn't in release notes.
