# Runtime 117.0.2045.28 (Sep. 18, 2023)

Release notes for Microsoft Edge WebView2 Runtime, release date: Sep. 18, 2023.


<!-- ====================================================================== -->
## Bug fixes

* Fixed a regression where calling `CoreWebView2.AddHostObjectToScript` twice for the same name hangs.  [Issue 3539](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3539)

* Removed visual search from the web capture context menu.  [Issue 3426](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3426)

* Removed the **Launch game** button from the default **No Internet Connection** error page.

* Added a lock for host object access from multithread.

* Removed the **Hide all annotations** option in PDF **Settings and more**.

* Removed the **Show all saved passwords** context menu item.

* Disabled the Mouse Gesture feature by default.  ([Issue #3737](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3737))

* Fixed a bug where mouse wheel scrolling was intermittently broken for visual hosting.

* Fixed a bug where downloading APK files in WebView2 crashes the WebView2 browser process.  ([Issue #3569](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3569))
