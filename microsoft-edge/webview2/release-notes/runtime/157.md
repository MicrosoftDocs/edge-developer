# Runtime 157.0.4341.42 (Nov. 6, 2026)

Release notes for Microsoft Edge WebView2 Preview Runtime, release date: Nov. 6, 2026.

In addition to the following WebView2 Runtime improvements, you can also use the new web platform features from Microsoft Edge 157; see [Microsoft Edge 157 web platform release notes (Nov. 5, 2026)](../../../web-platform/release-notes/157.md).


<!-- ====================================================================== -->
## Upcoming breaking change: Removing the `msAbydosHandwritingAttr` WebView2 browser flag

Starting with v159, WebView2 will remove the deprecated `msAbydosHandwritingAttr` browser flag.  After this change, passing `msAbydosHandwritingAttr` through `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`, registry-based browser arguments, or `CoreWebView2EnvironmentOptions.AdditionalBrowserArguments` will no longer enable the expected behavior.

For details, see [Upcoming breaking change: Removing the `msAbydosHandwritingAttr` WebView2 browser flag](./156.md#upcoming-breaking-change-removing-the-msabydoshandwritingattr-webview2-browser-flag)<!-- todo later: when 159.md exists, change link from 156 to 159 --> in _Runtime 156.0.4314.42 (Oct. 23, 2026)_.


<!-- ====================================================================== -->
## Upcoming breaking change: Required ACL setup for app-managed WebView2 Fixed Version runtimes on Windows

Starting with v159, WebView2 is strengthening the renderer sandbox for app-managed Fixed Version deployments.  Applications that deploy and manage an unpackaged Fixed Version runtime must configure and preserve the required Windows access control list (ACL) entries on the runtime folder during installation, runtime updates, and repair.

For details, see [Upcoming breaking change: Required ACL setup for app-managed WebView2 Fixed Version runtimes on Windows](./156.md#upcoming-breaking-change-required-acl-setup-for-app-managed-webview2-fixed-version-runtimes-on-windows)<!-- todo later: when 159.md exists, change link from 156 to 159 --> in _Runtime 156.0.4314.42 (Oct. 23, 2026)_.

## Bug fixes

* Fixed a WebView2 proxy release race condition.
* Removed a latent `stack-use-after-return` in the WebView2 embedded browser's File System Access (FSA) permission flow.
* Fixed a passkey sign-in hang due to null `HWND`.
* Restricted host object access to valid committed origins.
* Fixed a WebView2 browser-process crash when an application supplies an invalid shared-buffer handle.  _todo: pending payload-tracker confirmation_
* Blocked dangerous executable and script file types from opening via the shell on WebView2 Team SKU devices.  _todo: pending payload-tracker confirmation_
