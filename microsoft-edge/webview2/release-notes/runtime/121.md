# Runtime 121.0.2277.86 (Feb. 5, 2024)

Release notes for Microsoft Edge WebView2 Runtime, release date: Feb. 5, 2024.


<!-- ====================================================================== -->
## Bug fixes

* Ensured that the spellcheck language matches `put_Language` programmatically.  The customized context menu is also updated with correct spellchecks.

* Fixed a bug that stopped raising the `NavigationCompleted` event for some websites that load AV1-encoded videos.  ([Issue #3801](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3801))

* Fixed an issue where host-process COM resources would be released during WebView tear-down.  ([Issue #4226](https://github.com/MicrosoftEdge/WebView2Feedback/issues/4226))

* Fixed a bug that broke loading some social media apps such as Facebook, Twitter, and Linkedin.  This change is Runtime-specific.  ([Issue #4281](https://github.com/MicrosoftEdge/WebView2Feedback/issues/4281))
