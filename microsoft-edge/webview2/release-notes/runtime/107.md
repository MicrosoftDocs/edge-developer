# Runtime 107.0.1418.22 (Oct. 31, 2022)

Release notes for Microsoft Edge WebView2 Runtime, release date: Oct. 31, 2022.


<!-- ====================================================================== -->
## Bug fixes

* Fixed a bug in the WebView2 WinRT JS Projection tool (wv2winrt) where C++20 projects failed to compile.  ([Issue #2768](https://github.com/MicrosoftEdge/WebView2Feedback/issues/2768))

* Removed three-dot menu with a broken link from the downloads page.  ([Issue #2753](https://github.com/MicrosoftEdge/WebView2Feedback/issues/2753))

* Fixed a bug where it wasn't possible to dismiss the download popup after minimizing the window.
