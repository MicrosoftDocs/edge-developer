# Runtime 133.0.3065.39 (Feb. 10, 2025)

Release notes for Microsoft Edge WebView2 Runtime, release date: Feb. 10, 2025.

In addition to the following WebView2 Runtime improvements, you can also use the new web platform features from Microsoft Edge 133; see [Microsoft Edge 133 web platform release notes (Feb. 2025)](../../../web-platform/release-notes/133.md).


<!-- ====================================================================== -->
## Bug fixes

* Added the missing **Close** button in the **Download** flyout.

* Fixed a race condition that occurred when the Web Request Response event never occurs.
