# Runtime 155.0.4283.45 (Oct. 12, 2026)

Release notes for Microsoft Edge WebView2 Runtime, release date: Oct. 12, 2026.

In addition to the following WebView2 Runtime improvements, you can also use the new web platform features from Microsoft Edge 155; see [Microsoft Edge 155 web platform release notes (Oct. 8, 2026)](../../../web-platform/release-notes/155.md).


<!-- ====================================================================== -->
#### Bug fixes

* Fixed incorrect viewport in minimal mode.
* Fixed JAWS support in minimal window.
* Fixed an issue where `WebResourceRequested` events for service workers and shared workers weren't correctly scoped to the WebView2 profile.
* Prevented WebView2 from hiding the pointer over the native host UI while typing.
