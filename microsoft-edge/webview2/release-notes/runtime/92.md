# Runtime 92.0.902.49 (Jul. 26, 2021)

Release notes for Microsoft Edge WebView2 Runtime, release date: Jul. 26, 2021.


<!-- ====================================================================== -->
## Bug fixes

* Fixed a bug where mouse left click doesn't dismiss context menu.

* Fixed a bug where special browser keys such as `Refresh`, `Home`, and `Back` can't be disabled by `AreBrowserAcceleratorKeysEnabled`.

* Fixed a bug that [AllowSingleSignOnUsingOSPrimaryAccount](/microsoft-edge/webview2/reference/win32/icorewebview2environmentoptions#get_allowsinglesignonusingosprimaryaccount) doesn't work properly with WebView2 when a `WebResourceRequested` event handler is attached.  ([Issue #1183](https://github.com/MicrosoftEdge/WebViewFeedback/issues/1183))

* Downloading a file no longer breaks WebView2 `DefaultBackgroundColor` transparency.  ([Issue #1108](https://github.com/MicrosoftEdge/WebViewFeedback/issues/1108))

* Fixed a bug where right-clicking a link crashes the WebView2 host app.

* Fixed a reliability bug that could crash the host app process when moving to a newer Edge WebView2 Runtime version.

* Fixed a bug that broke the `IsBuiltInErrorPageEnabled` property, which turned off the error page that's displayed when there's a navigation failure or render process failure.  ([Issue #634](https://github.com/MicrosoftEdge/WebViewFeedback/issues/634))
