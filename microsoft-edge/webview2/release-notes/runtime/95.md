# Runtime 95.0.1020.30 (Oct. 25, 2021)

Release notes for Microsoft Edge WebView2 Runtime, release date: Oct. 25, 2021.


<!-- ====================================================================== -->
## Bug fixes

* Fixed a bug in the Client Certificate API, when the correct certificate was not selected.  ([Issue #1666](https://github.com/MicrosoftEdge/WebViewFeedback/issues/1666))

* Fixed bug where `window.chrome.webview` was unavailable in new windows in the same parent domain.  ([Issue #1144](https://github.com/MicrosoftEdge/WebViewFeedback/issues/1144))
