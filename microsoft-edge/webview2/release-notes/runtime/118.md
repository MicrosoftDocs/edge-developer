# Runtime 118.0.2088.41 (Oct. 16, 2023)

Release notes for Microsoft Edge WebView2 Runtime, release date: Oct. 16, 2023.


<!-- ====================================================================== -->
## Bug fixes

* Disabled installing CRX in WebView2.

* Fixed an initialization failure when the app has a DPI awareness compatibility setting applied.  ([Issue #3008](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3008))

* Fixed a bug where visual hosted owned windows couldn't take character input.

* Fixed an issue causing some UWP apps to be unable to input text.  ([Issue #3805](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3805))

* Fixed an initialization failure for apps that were using the Windows `PerProcessSystemDPIForceOff` compatibility setting.  ([Issue #3692](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3692))

* Fixed a Dialog Position Offset bug in WebView2.  ([Issue #3763](https://github.com/MicrosoftEdge/WebView2Feedback/issues/3763))
